계정 및 데이터 삭제 요청

서당(Seodang) · 앱 ID: kr.co.hygr.seodang · 최종 수정: 2026년 8월 26일

서당 계정과 계정에 연결된 개인정보의 삭제를 요청하는 방법을 안내합니다. 앱을 이미 삭제하셨거나 로그인할 수 없는 경우에도 아래 이메일 요청으로 처리하실 수 있습니다.

방법 1. 앱에서 직접 탈퇴

앱에 로그인할 수 있다면 가장 빠릅니다. 요청 즉시 처리되며 별도 확인 절차가 없습니다.

설정 화면 맨 아래 [회원 탈퇴] → 확인

학부모: 홈 우측 상단 ⋮ → 설정
학원 관리자: 홈 [설정]
PC 웹: 왼쪽 메뉴 설정 → 계정

탈퇴와 동시에 카카오 계정 연결도 자동으로 해제됩니다.

방법 2. 이메일로 요청

앱을 삭제했거나 카카오 계정을 사용할 수 없어 로그인이 불가능한 경우 아래 주소로 요청해 주세요.

받는 곳: contact@seodang.app

제목: 계정 삭제 요청

본문에 가입에 사용한 카카오 계정 이메일을 적어 주세요. 동명이인 확인을 위해 이용 중인 학원 이름과 본인(또는 자녀) 이름을 함께 적어 주시면 처리가 빠릅니다.

본인 확인 후 영업일 기준 7일 이내에 처리하고 결과를 회신해 드립니다. 회신 주소가 가입 계정과 다른 경우 추가 확인을 요청드릴 수 있습니다.
